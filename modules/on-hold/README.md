# On-Hold Modules

This directory contains Nix snippets and modules that have been **put on hold**.

These modules are not currently under active development or maintenance. This
does **not** mean they are abandoned or will never be revisited. They may return
to active development when priorities and resources allow.

The purpose of moving modules here is to keep the actively maintained codebase
focused and allow us to **ship faster** without being blocked by unfinished,
experimental, or lower-priority work.

Until a module is moved out of this directory, it should be considered:

- Not actively developed
- Potentially incomplete or outdated
- Subject to change without notice
- Unsupported for production use

Code in this directory is kept intentionally so that useful work and ideas are
not lost and can be picked up again in the future.
